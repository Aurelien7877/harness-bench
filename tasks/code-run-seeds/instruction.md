sim.py is a deterministic simulation. Run `python3 sim.py SEED` for the seeds 3, 7 and 11 and write answer.json with the number it prints as `inside=` for each seed.
Write answer.json with these fields and types:
{"seed_3": "number", "seed_7": "number", "seed_11": "number"}
Work in /workspace. Do not install packages or use the network.
